## 📋 Logo Usage Rules

### ✓ DO
- Use approved logo files only (`bonilo-logo.png` or `bonilo-logo.jpeg`)
- Maintain minimum clear space (height of "o")
- Respect minimum sizes (32px wordmark / 16px icon)
- Use correct color variants for backgrounds
- Test legibility at actual size
- Download PNG for transparent backgrounds
- Download JPEG for white backgrounds

### ✗ DON'T
- Never stretch, distort, or rotate
- Never change colors (except approved variants)
- Never add effects (shadows, glows, outlines)
- Never use below minimum size
- Never violate clear space
- Never create unapproved variations

## 📐 Technical Specifications

### File Formats
- **Raster**: PNG (transparency), JPEG (backgrounds)
- **Resolution**: 1200ppi high-resolution export
- **Color Mode**: sRGB (RGB)

### Asset Details
- **PNG Format**: Transparent background, supports alpha channel
- **JPEG Format**: White background, smaller file size
- **Resolution**: 1200ppi (print-ready quality)
- **Source**: Exported from 1200ppi high-resolution master

### Minimum Sizes
- **Wordmark**: 32px (digital) / 1 inch (print)
- **Icon**: 16px simplified / 0.5 inch (print)

### Clear Space
- **Minimum**: Height of "o" in bonilo
- **Enforcement**: All sides, all applications

## ✅ Quality Gates

All applications must pass these tests:

### 1. Legibility Test
- ✓ Logo readable at all sizes
- ✓ Text wordmark readable at 32px
- ✓ Clear in black & white
- ✓ No detail loss when scaled

### 2. Scale Test
- ✓ 3m signage readable from 10m
- ✓ 6m signage readable from 20m
- ✓ Mobile clear at actual size

### 3. Contrast Test
- ✓ WCAG 2.1 AAA compliance (7:1)
- ✓ Green on Cream: 7.2:1
- ✓ Dark on Cream: 12.8:1
- ✓ White on Green: 8.1:1

### 4. Print Test
- ✓ 1200ppi clarity: verified
- ✓ High-resolution PNG: provided
- ✓ Prints clearly on all substrates
