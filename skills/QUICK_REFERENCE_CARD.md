## 🎯 Text Formatting

```markdown
# Main Title
## Section Title
### Subsection

*italic* or _italic_
**bold** or __bold__
~~strikethrough~~

`inline code`
```

---

## 📝 Lists

```markdown
* Unordered item 1
- Unordered item 2  
+ Unordered item 3

1. Ordered item 1
2. Ordered item 2
3. Ordered item 2.1 (nested)
4. Ordered item 2.2
```

---

## 🔗 Links & Images

```markdown
[Link Text](https://example.com)
[Email](mailto:user@domain.com)
[Phone](tel:+21312345678)

![Alt Text](image-url "Optional Title")
```

## ⚡ Quick Templates

### Product Entry
```markdown
## PRODUCT NAME
**SKU**: [CODE] | **Brand**: [BRAND] | **Size**: [SIZE]
**Price**: DZD [AMOUNT] | **Stock**: [QUANTITY]
```

### Daily Report  
```markdown
## Report - [DATE]
**Sales**: DZD [AMOUNT] | **Transactions**: [COUNT]
**Top Product**: [NAME] - [QUANTITY] units
```

### Alert
```markdown
## 🔔 [SEVERITY] Alert
**Item**: [PRODUCT] | **Issue**: [DESCRIPTION]
**Action**: [REQUIRED ACTION] | **Contact**: [PERSON]
```
