## 2. LOGO SYSTEM

### 2.1 Primary Wordmark

**Description**: Lowercase "bonilo" in rounded sans-serif
**Features**:
- Medium stroke weight
- Open counters
- Generous letter spacing
- Subtle smile curve below (optional)

**Usage**:
- Primary brand identifier
- Storefront signage
- Website headers
- Marketing materials

**Minimum Size**: 32px height (digital) / 1 inch height (print)

### 2.2 Standalone Icon

**Description**: Abstract lowercase "b" within circle
**Construction**: Two overlapping circles forming bowls of "b"
**Features**:
- Circular outer geometry (95% of canvas)
- Subtle smile element (optional at >64px)
- Simplified version for sizes below 32px

**Usage**:
- App icon
- Social media profile
- Favicon
- Small-space applications

**Minimum Size**: 16px (simplified version automatically)

### 2.3 Logo Variants

**Available Versions**:
1. Primary Wordmark (green with smile)
2. Primary Wordmark (green, no smile)
3. Standalone Icon (green)
4. Horizontal Lockup (icon + wordmark)
5. Stacked Lockup (icon over wordmark)
6. Monochrome Black
7. Inverse White
8. Icon Simplified (micro sizes)

### 2.4 When to Use Each Variant

**Primary Wordmark**: Default for all applications
**Standalone Icon**: App icons, favicons, social profiles
**Horizontal Lockup**: Letterheads, wide banners
**Stacked Lockup**: Square formats, mobile headers
**Monochrome**: Single-color printing, light backgrounds
**Inverse**: Dark backgrounds, photography
**Simplified**: Sizes below 32px

### 2.5 Smile Element Rules

**Standard Version** (≥64px):
- Subtle curve below wordmark
- 4px stroke weight
- Rounded caps
- Extends 95% of wordmark width

**Simplified Version** (<64px):
- Smile removed for clarity
- Focus on letterforms only

**Never**:
- Amazon-style full-width swoop
- Dominant or oversized smile
- Sharp or angular smile
- Smile that reduces legibility

## 3. COLOR PALETTE

### 3.1 Primary Palette

**Primary Green**
- HEX: #3D7C4F
- RGB: 61, 124, 79
- CMYK: 70, 25, 65, 10
- Pantone: 7483 C (approximate)
- Usage: Primary brand color (50-70% of design)

**Warm Cream**
- HEX: #FDFBF7
- RGB: 253, 251, 247
- CMYK: 1, 2, 4, 0
- Usage: Backgrounds, breathing space (20-40% of design)

**Soft Amber** (Accent)
- HEX: #E8A05D
- RGB: 232, 160, 93
- CMYK: 5, 40, 65, 0
- Usage: ACCENT ONLY (≤10% of design)

### 3.2 Neutral Palette

**Neutral Dark** (Text)
- HEX: #2C2C2C
- RGB: 44, 44, 44
- CMYK: 65, 60, 60, 50

**Neutral Mid** (Secondary Text)
- HEX: #5A5A5A
- RGB: 90, 90, 90
- CMYK: 60, 50, 50, 20

**Light Green** (Backgrounds)
- HEX: #E8F3EC
- RGB: 232, 243, 236
- CMYK: 10, 0, 10, 0

### 3.3 Forbidden Colors

**NEVER USE**:
- Dominant red (aggressive)
- Black + gold (luxury)
- Neon or electric colors (trendy)
- Tech blue (corporate)
- Discount yellow (cheap)

### 3.4 Color Accessibility

**WCAG 2.1 AAA Compliance**:
- Green (#3D7C4F) on Cream (#FDFBF7): 7.2:1 ✓
- Dark (#2C2C2C) on Cream (#FDFBF7): 12.8:1 ✓
- White (#FDFBF7) on Green (#3D7C4F): 8.1:1 ✓
- Amber (#E8A05D) on Cream (#FDFBF7): 4.6:1 (AA, use for large text only)

**Minimum Contrast Ratios**:
- Small text (<18px): 4.5:1
- Large text (≥18px): 3:1
- UI components: 3:1

## 4. TYPOGRAPHY

### 4.1 Primary Typeface

**Family**: Rounded Sans-Serif

**Recommended Fonts**:
1. Nunito (Google Fonts) — Primary recommendation
2. DM Sans (Google Fonts)
3. Inter Rounded
4. Rounded Mplus 1c
5. System fallback: -apple-system, BlinkMacSystemFont, Roboto

**Weights**:
- Regular (400) — Body text
- Medium (500) — Wordmark, headings
- Semibold (600) — Emphasis, CTAs

**Characteristics**:
- Open counters
- Medium stroke weight
- Human, friendly curves
- High legibility at all sizes

### 4.2 Typography Scale

**Display** (Storefront, Hero)
- Size: 64–96px
- Weight: 500
- Line-height: 1.1
- Letter-spacing: -0.02em

**Heading 1**
- Size: 36–48px
- Weight: 600
- Line-height: 1.2
- Letter-spacing: -0.01em

**Heading 2**
- Size: 28–32px
- Weight: 600
- Line-height: 1.3

**Body Large**
- Size: 18px
- Weight: 400
- Line-height: 1.7
- Color: #5A5A5A

**Body Standard**
- Size: 16px
- Weight: 400
- Line-height: 1.6
- Color: #5A5A5A

**Small Text / Labels**
- Size: 13–14px
- Weight: 400–500
- Line-height: 1.5
- Color: #888888

### 4.3 Typography Rules

**DO**:
- Prioritize readability over expression
- Use generous line-height (1.5–1.7)
- Maintain clear hierarchy
- Use neutral, friendly tone

**DON'T**:
- Use condensed fonts
- Use ultra-modern or decorative fonts
- Use all caps for body text
- Sacrifice legibility for style

## 5. CLEAR SPACE & SIZING

### 5.1 Clear Space

**Minimum Clear Space**: Height of the "o" in "bonilo"

**Enforcement**:
- All sides of logo must respect this clear space
- No text, graphics, or elements inside clear space
- Applies to all logo variants

**Visual Guide**:
```
[  ← o-height →  ]
[                ]
[    BONILO     ]
[                ]
[  ← o-height →  ]
```

### 5.2 Minimum Sizes

**Digital**:
- Wordmark: 32px height minimum
- Icon: 16px minimum (simplified version)
- Icon (with smile): 64px minimum

**Print**:
- Wordmark: 1 inch (25.4mm) height minimum
- Icon: 0.5 inch (12.7mm) minimum

**Exceptions**:
- Favicon: 16px (simplified icon only)
- Small UI elements: 24px (simplified icon only)

### 5.3 Maximum Sizes

**No maximum**, but consider:
- Storefront: Typically 3–6 meters
- Readable from 10–20 meters distance
- Maintain proportions at all scales

## 6. APPLICATIONS

### 6.1 Storefront Signage

**Specifications**:
- Primary wordmark in green (#3D7C4F)
- Cream or white background (#FDFBF7)
- Minimum height: 3 meters for neighborhood visibility
- Readable from 10 meters minimum

**Materials**:
- Painted wood (preferred)
- Painted metal
- Channel letters with LED (warm white 2700K)
- Avoid: Neon, bright LEDs, digital screens

**Lighting**:
- Soft, warm ambient lighting
- No harsh spotlights
- Natural daylight integration

### 6.2 App Icon

**Platform Requirements**:

**iOS**:
- 1024×1024px (App Store, required)
- 180×180px (iPhone)
- 167×167px (iPad Pro)
- 152×152px (iPad)
- 120×120px (iPhone SE)

**Android**:
- 512×512px (Play Store, required)
- 192×192px (xxxhdpi)
- 144×144px (xxhdpi)
- 96×96px (xhdpi)
- 72×72px (hdpi)

**Design**:
- Green background (#3D7C4F)
- White icon (#FDFBF7)
- Simplified version for sizes <128px
- Rounded corners applied by OS

**Format**:
- PNG (no alpha for iOS)
- Adaptive icon for Android
- Safe zone: 66dp circular area

### 6.3 Favicon

**Required Sizes**:
- 32×32px (standard)
- 16×16px (browser tab)
- 180×180px (Apple touch icon)
- 192×192px (Android chrome)

**Format**:
- ICO (multi-size)
- PNG (individual sizes)
- SVG (modern browsers)

**Design**:
- Simplified icon only
- No smile at <32px
- Clear "b" form visible

### 6.4 Shopping Bag

**Specifications**:
- Kraft paper (natural or cream)
- Green wordmark (#3D7C4F)
- Centered placement
- Generous spacing around logo
- Optional: "Your neighborhood grocery" tagline below

**Materials**:
- Recyclable kraft paper
- Water-based ink printing
- Cotton or paper handles (green)

**Sizes**:
- Small: 25×30cm
- Medium: 30×40cm
- Large: 40×50cm

### 6.5 Receipt Header

**Specifications**:
- Wordmark centered at top
- Store information below (address, phone)
- Monospace font for transaction details
- Black ink on thermal paper

**Layout**:
```
       bonilo
Your neighborhood grocery
   123 Main Street
   (555) 123-4567

------------------------
[Transaction details]
```

### 6.6 UI Buttons

**Primary Button**:
- Background: #3D7C4F
- Text: #FDFBF7
- Border-radius: 48px (fully rounded)
- Padding: 16px 32px (desktop) / 12px 24px (mobile)
- Font: 500 weight, 16px (desktop) / 14px (mobile)

**Secondary Button**:
- Background: #FDFBF7
- Text: #3D7C4F
- Border: 2px solid #3D7C4F
- Same border-radius and padding as primary

**Accent Button** (use sparingly):
- Background: #E8A05D
- Text: #FDFBF7
- Same border-radius and padding

**Hover States**:
- Transform: translateY(-1px)
- Shadow: 0 4px 12px rgba(61,124,79,0.3)
- Transition: 200ms ease

## 7. QUALITY STANDARDS

### 7.1 Legibility Test

**Requirements**:
✓ Icon readable at 16px
✓ Wordmark readable at 32px
✓ All elements clear in black & white
✓ No detail loss when scaled

**Testing**:
1. View at actual size on screen
2. Print at minimum size
3. Test from intended viewing distance
4. Verify in grayscale

### 7.2 Scale Test

**Requirements**:
✓ 3m signage readable from 10m
✓ 6m signage readable from 20m
✓ Mobile sizes clear at actual device size
✓ Print materials legible at arm's length

### 7.3 Contrast Test

**Requirements**:
✓ WCAG 2.1 AAA compliance (7:1 for small text)
✓ WCAG 2.1 AA minimum (4.5:1)
✓ Test with accessibility tools
✓ Verify in various lighting conditions

**Tools**:
- WebAIM Contrast Checker
- Stark (Figma/Sketch plugin)
- Color Oracle (colorblind simulator)

### 7.4 Print Test

**Requirements**:
✓ 300dpi minimum resolution
✓ CMYK conversion accurate
✓ Pantone spot color option provided
✓ Prints clearly on various substrates

**Materials to Test**:
- Offset printing (coated/uncoated)
- Digital printing
- Screen printing (fabric)
- Thermal printing (receipts)

## 8. TECHNICAL SPECIFICATIONS

### 8.1 File Formats

**Vector Masters** (Editable):
- SVG (web, digital)
- AI (Adobe Illustrator)
- PDF (print, archival)

**Raster Exports** (Fixed):
- PNG (transparent backgrounds)
- JPG (photography backgrounds)

**Sizes Required**:
- 16px, 32px, 64px, 128px, 256px, 512px, 1024px

### 8.2 Color Modes

**Digital (Web, App)**:
- Color space: sRGB
- Format: PNG, SVG
- Profile: sRGB IEC61966-2.1

**Print (Offset, Digital)**:
- Color space: CMYK or Pantone
- Format: PDF, AI, EPS
- Profile: ISO Coated v2 (ECI)
- Resolution: 300dpi minimum

### 8.3 Naming Convention

```
bonilo_[type]_[variant]_[color]_[size].[format]

Examples:
bonilo_wordmark_primary_green_1024px.png
bonilo_icon_simplified_white_512px.svg
bonilo_lockup_horizontal_black_print.pdf
```

## 9. GOVERNANCE & COMPLIANCE

### 9.1 Brand Authority

**Single Source of Truth**:
- One design owner
- One approved brand package
- No local reinterpretations
- No unapproved modifications

**Approval Process**:
1. All new applications require design review
2. Quality gates must be passed
3. Technical specs must be met
4. Documentation must be updated

### 9.2 Core Principles (Locked)

**1. Consistency = Trust**
- One design language across all touchpoints
- Zero tolerance for brand drift
- Regular audits of applications

**2. Simplicity Over Cleverness**
- If it feels loud, trendy, or salesy → reject it
- Calm and human always win
- No gimmicks or tricks

**3. Emotional Safety First**
- Every touchpoint must reduce stress
- Warm, welcoming, reliable
- Never aggressive or pushy

**4. Quality Over Speed**
- Take time to do it right
- Test thoroughly before launch
- Maintain high standards always

**5. Accessibility is Non-Negotiable**
- WCAG 2.1 AAA compliance required
- Test with real users
- Consider all abilities

### 9.3 Enforcement

**Violations**:
- Unapproved logo modifications
- Wrong colors or fonts
- Missing clear space
- Failed quality gates
- Inconsistent applications

**Consequences**:
- Immediate correction required
- Design review mandatory
- Documentation of issue
- Prevention of future violations

### 9.4 Updates & Versioning

**Current Version**: v1.0 (Locked)

**Update Process**:
1. Proposal with rationale
2. Design review committee
3. Testing and validation
4. Documentation update
5. Rollout with timeline

**Version History**:
- v1.0 (2026-02-07): Initial production release

## 10. FINAL PRINCIPLE

**The Bonilo Test**:

Before approving any application, ask:

**Does this feel**:
- ✓ Calm?
- ✓ Human?
- ✓ Dependable?
- ✓ Warm?

**Does this NOT feel**:
- ✗ Loud?
- ✗ Clever?
- ✗ Trendy?
- ✗ Salesy?

**If any "✗" answer is YES → reject and revise.**
