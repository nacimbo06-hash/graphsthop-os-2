# BONILO LOGO USAGE GUIDE

## Quick Reference: Do's and Don'ts

### ✓ DO

1. **Use approved logo files only**
   - Source files from official brand package
   - Never recreate or redraw the logo
   - Use vector formats when scaling

2. **Maintain clear space**
   - Minimum = height of "o" in bonilo
   - Apply on all sides
   - Keep clear of text, graphics, edges

3. **Use correct color variants**
   - Green (#3D7C4F) on light backgrounds
   - White (#FDFBF7) on dark backgrounds
   - Black (#2C2C2C) for single-color printing

4. **Respect minimum sizes**
   - Wordmark: 32px digital / 1" print
   - Icon: 16px (simplified) / 0.5" print
   - Test legibility at actual size

5. **Choose appropriate variant**
   - Primary wordmark for most uses
   - Icon for app/favicon/social
   - Lockups for specific layouts

6. **Maintain proportions**
   - Never stretch or distort
   - Lock aspect ratio when scaling
   - Use original proportions always

### ✗ DON'T

1. **Never alter the logo**
   - Don't change colors (except approved variants)
   - Don't rearrange elements
   - Don't add effects (shadows, glows, bevels)
   - Don't rotate or skew
   - Don't outline or add strokes

2. **Never violate clear space**
   - Don't place too close to edges
   - Don't crowd with other elements
   - Don't overlap with text or graphics

3. **Never use wrong backgrounds**
   - Don't use on busy patterns
   - Don't use on low-contrast backgrounds
   - Don't use on photographs (use lockup with bg)

4. **Never create variations**
   - Don't add taglines to logo
   - Don't combine with other logos (except partnerships)
   - Don't create department-specific versions

5. **Never compromise legibility**
   - Don't use below minimum size
   - Don't use smile at micro sizes
   - Don't sacrifice clarity for style

6. **Never use forbidden colors**
   - No red, neon, or electric colors
   - No black+gold combinations
   - No tech blue or discount yellow

## Detailed Usage Guidelines

### Backgrounds

**APPROVED BACKGROUNDS**:
- Cream (#FDFBF7) — preferred
- White (#FFFFFF)
- Light green (#E8F3EC)
- Dark (#2C2C2C) — use white logo
- Photography (with sufficient contrast/overlay)

**REJECTED BACKGROUNDS**:
- Busy patterns or textures
- Low-contrast colors (mid-grays)
- Competing green shades
- Gradients (unless very subtle)

### Color Combinations

**PRIMARY** (most common):
- Green logo on cream background
- Green logo on white background
- Green logo on light green background

**INVERSE** (dark backgrounds):
- White logo on dark background (#2C2C2C)
- White logo on green background (sparingly)
- White logo on photography (with overlay)

**MONOCHROME** (single-color printing):
- Black logo on white/light backgrounds
- White logo on dark backgrounds

### Placement

**DIGITAL**:
- Top-left: website headers, app screens
- Center: splash screens, email headers
- Bottom: footers (smaller size acceptable)

**PRINT**:
- Top-center: letterheads, receipts
- Front-center: shopping bags, packaging
- Top-left: business cards, invoices

**ENVIRONMENTAL**:
- Eye-level: storefront signage (1.5-2m from ground)
- Center: interior wall graphics
- Wayfinding: consistent placement

### Sizing Guidance

**DIGITAL SCREENS**:
- Hero/Header: 64-96px
- Navigation: 32-48px
- Footer: 24-32px
- Favicon: 16px (simplified)
- App Icon: 60-180px (based on platform)

**PRINT MATERIALS**:
- Business Card: 1-1.5 inches
- Letterhead: 1.5-2 inches
- Poster/Signage: 3-6 inches+
- Shopping Bag: 4-8 inches

**ENVIRONMENTAL**:
- Storefront: 3-6 meters (readable from 10-20m)
- Interior Signage: 0.5-1 meter
- Wayfinding: Based on viewing distance

## Partner & Co-Branding

### Rules for Co-Branding

1. **Equal Visual Weight**
   - Partner logos should be similar size
   - Maintain consistent visual hierarchy
   - Respect both brands' guidelines

2. **Separation**
   - Use vertical separator line if needed
   - Maintain clear space for both logos
   - Never merge or overlap logos

3. **Approved Only**
   - All co-branding must be approved
   - Review partner brand guidelines
   - Test legibility and contrast

### Preferred Co-Brand Layout

```
[bonilo logo]  |  [Partner logo]
```

- Vertical separator: 1px, neutral gray
- Equal spacing on both sides
- Both logos same height or visual weight

## Digital Applications

### Website

**Header** (Primary):
- Horizontal lockup or wordmark
- 48-64px height
- Links to homepage
- Green on cream background

**Footer**:
- Wordmark or horizontal lockup
- 24-32px height
- Monochrome or muted green acceptable

**Favicon**:
- 32×32px and 16×16px
- Simplified icon only
- No smile at 16px

### Social Media

**Profile Picture**:
- Icon only (circular)
- Green background with white icon
- 400×400px minimum
- Simplified for small displays

**Cover Photo**:
- Wordmark or horizontal lockup
- Generous whitespace
- Cream or light green background

**Posts**:
- Use full lockup when space allows
- Icon acceptable for small badges
- Maintain clear space

### Email

**Header**:
- Wordmark centered
- 48-64px height
- Links to website
- Retina-ready (2× resolution)

**Signature**:
- Small wordmark or icon
- 24-32px height
- Links to website

## Print Applications

### Business Card

**Front**:
- Wordmark top-left or center
- 1-1.5 inches height
- Sufficient clear space
- Green on cream or white

**Back**:
- Optional icon watermark
- Subtle, light green tint
- No primary logo

### Letterhead

**Header**:
- Wordmark centered or left-aligned
- 1.5-2 inches height
- 1 inch from top margin
- Green on white/cream

### Packaging

**Shopping Bags**:
- Wordmark centered
- 4-8 inches depending on bag size
- Kraft paper with green print
- "Your neighborhood grocery" optional tagline

**Product Labels**:
- Icon or wordmark based on space
- Maintain legibility
- Test at actual size

## Environmental Applications

### Storefront Signage

**Main Sign**:
- Primary wordmark
- 3-6 meters height
- Readable from 10-20 meters
- Warm lighting (2700K)

**Materials**:
- Painted wood (preferred)
- Channel letters (warm LED)
- Painted metal
- No neon or digital displays

### Interior Signage

**Department Signs**:
- Wordmark or icon
- 0.5-1 meter height
- Consistent placement
- Clear wayfinding

**Wall Graphics**:
- Large wordmark or icon
- Decorative or branding purpose
- Subtle, not overwhelming
- Cream or light green backgrounds

## Common Mistakes

### ❌ INCORRECT EXAMPLES

**1. Stretching / Distortion**
```
bonilo → BBOONNIILLOO
```
Never stretch or compress the logo

**2. Wrong Colors**
```
bonilo (in red)
bonilo (in blue)
bonilo (in yellow)
```
Only use approved color variants

**3. Effects**
```
bonilo (with drop shadow)
bonilo (with glow)
bonilo (with gradient)
```
Keep logo flat and clean

**4. Too Small**
```
bonilo (8px height)
```
Respect minimum sizes

**5. Crowded**
```
SALE! bonilo OPEN
```
Maintain clear space

**6. Rotated**
```
bonilo (at 45° angle)
```
Always horizontal, never rotated
